# KAIRA Backend

Voice-first business operations backend for small businesses: customers, invoices, payments, bills,
receivables, cash-flow forecasting, what-if simulation, and an AI assistant that turns Telugu, Hindi or
English requests into **owner-approved**, audited operations.

FastAPI · Pydantic v2 · SQLAlchemy 2 · Alembic · PostgreSQL · Sarvam AI (Saaras STT, Bulbul TTS, sarvam-105b).

## Quick start (only Docker required)

```powershell
.\scripts\setup.ps1     # Windows   (./scripts/setup.sh on Linux/macOS)
.\scripts\start.ps1
```

* API docs: http://127.0.0.1:8000/docs
* Demo login: `DEMO_OWNER_EMAIL` / `DEMO_OWNER_PASSWORD` from `.env` (generated by setup)
* Voice and the Sarvam LLM: add `SARVAM_API_KEY` to `.env`, then run `start` again. Without it, typed input works through the rules extractor.

Other scripts: `stop`, `verify` (all quality gates), `backup`, `restore`.

## Try the demo flow

```
POST /api/v1/auth/login            {"email": "demo@kaira.local", "password": "<from .env>"}
POST /api/v1/assistant/extract     {"transcript": "Ramesh paid me 5,000 rupees today. He will clear the remaining amount next Monday."}
POST /api/v1/actions/{id}/approve  (header X-CSRF-Token from the login response)
POST /api/v1/cashflow/simulate     {"largest_customer": true, "delay_days": 15}
```

## Development

```
.venv\Scripts\python.exe -m pytest -q          # needs `docker compose up -d db`
.venv\Scripts\python.exe -m ruff check . ; .venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
python -m app.cli export-openapi               # after any API change (CI enforces it)
```
